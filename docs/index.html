CLAI+

My fork of CLAI for running agent teams with MCP tools and workspace schedules. I added weekly time blocks, a check for work before the agent runs, and scripts to get things ready and clean up.

🔌 MCP tools and CLAI+ Control MCP

  • Give your agents MCP tools. Add a local or remote MCP server in Settings → MCP Servers, then choose which workspaces and agents can use it.
  • Check CLAI+ from another app. I’ve been building CLAI+ Control MCP on a separate development branch. With workspace access you grant, a local MCP client like Codex can check a schedule and see what’s running or waiting.
  • Codex plugin idea. I’m looking at a local plugin to make the Control MCP connection easier to set up.

🛠️ What I added to the public fork

🗓️ Workspace schedules

  • Intervals and cron. Set an interval as short as 15 seconds, or use cron for fixed times.
  • Weekly time blocks. Pick the hours each workspace can run. The grid uses 15-minute blocks and a saved timezone.
  • Run controls. Pause a workspace schedule or use Run agent now. A due workspace can check its own schedule while another one is busy.

⚙️ Condition, Before, and After scripts

  • Condition. Check if there’s work first. For example, look for a new file before starting a model turn.
  • Before and After. Set up what the workspace needs for the run, then clean up when it’s done.
  • Script approvals. Test a script in settings and review its exact contents before running it unattended. If cleanup gets interrupted, you can see what’s pending and decide what to do with it.

Platform support. Automatic enhanced schedules use the macOS wake monitor and need the app running. Other platforms can use the regular scheduler.

🧪 What I’m running in my local build

These additions are still outside the public branch.

  • Run queue. See what’s running and what’s waiting in Settings → Scheduling. Set how many scheduled runs can go at once and how many can wait in each workspace.
  • Tray controls. Keep CLAI+ running in the tray and bring the window back when you need it.
  • Workspace add-ons. Manage Todoist from workspace settings. The Google file worker supports review notes tied to a specific part of the file.
